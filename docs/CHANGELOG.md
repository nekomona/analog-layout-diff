# Changelog

## 0.17.1

Restore multipart-path properties after connectivity callbacks and before
property-linked displays. Preserve strict property readback.

## 0.17.0

Group implementation into functional packages and document runtime boundaries.

## 0.16.0

Pair moved vias and distinguish movement/stretching from other modifications.

## 0.15.x

Capture and reconstruct native ROD multipart paths, handle dangling recipe nets,
and stabilize replay ordering. Add conservative anonymous-figure matching.

## 0.14.x

Offer supported-only checkpoints with two explicit loss confirmations and a
complete omission audit. Keep strict APIs rejecting unsupported native content.

## 0.13.x

Add temporary review leases, guarded checkpoint restore, Git-centric history
selection and inline progress feedback.

## 0.12.x

Support persistent placement/routing annotations and local text displays.

## 0.11.x and earlier

Add native review styles, group boundaries and connectivity counts; support
logical groups and compact streaming storage with optional C++ acceleration.
Keep routes, markers and Steiners outside capture scope.
